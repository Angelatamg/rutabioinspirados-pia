# RutaBio · Rutas de reparto con ACO y PSO en el Centro de Monterrey

Proyecto integrador de algoritmos bioinspirados. Compara **ACO** (colonia de hormigas) y **PSO** (enjambre de partículas), solos y con búsqueda local 2-opt, en el problema del agente viajero sobre la **red vial real del Centro de Monterrey** (OpenStreetMap, 457 nodos, 838 tramos dirigidos, calles de un solo sentido incluidas).

- **Página web (demo interactiva):** abre `index.html` o la página publicada con GitHub Pages.
- **Notebook de Google Colab:** `RutaBio_PIA.ipynb`. Descarga las calles de OpenStreetMap, corre los 720 experimentos y genera las gráficas.
- **Reporte:** `Reporte_RutaBio_2252149.pdf` y `.docx`.
